## 2025-07-16 - [Missing Authentication on Worker Administrative Endpoint]
**Vulnerability:** The `/sync` endpoint in the `ctftime-sync` Cloudflare Worker was exposed publicly without authentication, allowing anyone to trigger on-demand syncs and cache regenerations by visiting the endpoint. This could be exploited for abuse (resource exhaustion via excessive external API calls, violating CTFTime API rate limits and potentially getting the Worker's IP or User-Agent banned).
**Learning:** Cloudflare Workers exposing administrative or state-mutating HTTP triggers (like bypassing cache to perform heavy remote fetches) must implement explicit authorization checks. It is not safe to leave an endpoint public just because it is not explicitly linked or documented.
**Prevention:** Always verify authorization (e.g., verifying a secret from environment bindings like `env.SYNC_SECRET` against the `Authorization` header) before executing expensive or side-effecting operations on HTTP endpoints exposed by Workers. Ensure tests mock these secrets using `miniflare.bindings` in `vitest.config.ts`.
