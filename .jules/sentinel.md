## 2025-03-04 - Secure Administrative/On-demand Sync Endpoints in Cloudflare Workers
**Vulnerability:** The `/sync` endpoint in the `ctftime-sync` Cloudflare Worker was exposed publicly without authentication. This allowed unauthenticated users to trigger the on-demand sync, which fetches data from the CTFtime API and updates KV cache, posing a risk of resource exhaustion or API rate-limiting denial of service if repeatedly called.
**Learning:** Cloudflare Workers exposing administrative or on-demand trigger endpoints manually via HTTP paths must explicitly implement authorization checks. Even if the primary function operates securely via a Cron Trigger, any direct HTTP routes used to bypass the schedule must be protected, as they run on the same public origin by default.
**Prevention:** Always implement an authorization check for administrative/trigger endpoints. Verify a secret token from the Worker's environment bindings against an `Authorization` header before processing the request. This ensures only authorized clients or administrators can trigger sensitive actions.
